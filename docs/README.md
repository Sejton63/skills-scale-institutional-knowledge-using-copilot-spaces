# OctoAcme Project Management Docs

This repository contains the core project management guidance used by OctoAcme. The README acts as a landing page for the team and links to the full process library.

## Project management process summary

OctoAcme follows a lightweight, iterative project lifecycle: initiation, planning, execution, release, and retrospective. The team emphasizes customer value, clear ownership, measurable outcomes, iterative delivery, and regular communication across stakeholders and delivery roles.

## Why this matters

The README gives people a clear starting point for onboarding, planning, and execution while helping keep process documentation consistent and easy to navigate.

## Recommended workflow

- Start with the project overview and initiation guide for new work
- Use planning and execution docs during delivery
- Reference release and retrospective guidance at milestones and handoff points
- Keep project artifacts updated as work evolves
